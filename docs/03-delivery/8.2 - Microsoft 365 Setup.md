# 8.2 Microsoft 365 setup

What the owner does once so Jitmo can sign in to Microsoft 365. Nothing here is a secret: the app is a public client and has no client secret.

## 1. Register the app

1. Open the Microsoft Entra admin centre (entra.microsoft.com), then **App registrations → New registration**.
2. Name: `Jitmo`. Supported account types: **Accounts in any organizational directory and personal Microsoft accounts** (this is the `common` tenant Jitmo uses by default; pick a single tenant if the test accounts are all in one, and save its id as `ms365_tenant`).
3. Redirect URI: platform **Mobile and desktop applications**, value `http://127.0.0.1`. Jitmo picks a free port for each sign-in; Microsoft allows any port on the loopback address.
4. Under **Authentication**, set **Allow public client flows** to **Yes**.
5. Copy the **Application (client) ID**. It is a 36-character id like `12345678-abcd-4ef0-9876-1234567890ab`.

## 2. Add the permissions

Under **API permissions → Add a permission → Microsoft Graph → Delegated permissions**, add only these (least privilege, PS5):

| Permission | Why |
|---|---|
| `offline_access` | Keeps you signed in. |
| `Mail.ReadWrite` | Read mail, archive, move, save drafts. |
| `Mail.Send` | Send an email after the confirm. |
| `Calendars.ReadWrite` | Read the calendar, add, move and answer invites. |
| `Calendars.Read.Shared` | See a colleague's free and busy times. |
| `People.Read` | Find an exact name's email address. |

OneDrive (`Files.ReadWrite`) and Teams (`ChatMessage.Send`) are not requested yet because those connectors are not connected to Graph.

## 3. Tell Jitmo

Open the bar and say:

```
set Microsoft client id to 12345678-abcd-4ef0-9876-1234567890ab
```

Restart Jitmo, then say `sign in to Microsoft`. The browser opens on the Microsoft sign-in page; after you accept, the tab says you can close it. The refresh token is kept in Windows Credential Manager (`jitmo/ms365/refresh-token`). `sign out of Microsoft` removes it.

## 4. Check it

- `Any urgent emails?` and `What's on my calendar today?` should answer from the real account.
- `Email <exact name> that the report is ready` shows a confirm with the name, then sends. A name that is not in your People list exactly is refused, not guessed.
- Not connected yet, and said so plainly: saving attachments to OneDrive, forwarding an attachment to Teams, sending the weekly report, attaching files to email.

## Test accounts

For the test set (04) use a throw-away Microsoft 365 developer tenant with a seeded mailbox and calendar. Do not run it against a real inbox.
